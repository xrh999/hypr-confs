# Take note:
My wallpaper is from [Fedora 43](https://fedoraproject.org/wiki/Wallpapers#Fedora_43), placed in ~/Wallpapers/Wocket.png

To replace it to your wallpaper, look for the relevant variables in both hypr/hyprlock.conf and hyprpaper.conf

# Requirements:
Ensure that waybar, rofi, swaync are installed on your system

# Misc
You can remove the shaders folder and the corresponding keybind in hypr/modules/keybinds.lua under software dimming
I have it bc my monitor is buns and its lowest brightness is too bright for me still

For the navigation between windows, I use vim hjkl, if you want to switch it back to arrows, you can do so by editing hypr/modules/keybinds.lua
